# Zenius Scripting Language

Zenius Scripting Language(ZSL)는 Zenius 제품에서 전달받은 데이터로 조건을 판정하고 값을 계산하는 제한형 표현식 언어다. 템플릿은 일반 텍스트와 `${...}` 표현식 구간으로 구성된다.

## 표현식 범위

- 중첩 괄호와 사칙연산 `+`, `-`, `*`, `/`
- 삼항 연산 `조건 ? 참일 때의 값 : 거짓일 때의 값`
- 논리 연산 `&&`, `||`와 널 병합 연산 `??`
- 전용 함수 `GET(객체, ...프로퍼티명)`를 통한 객체 속성 읽기

변수 선언, 할당, 함수 선언, 제어문과 직접 속성 접근은 문법에서 제외한다. 전역 변수와 미등록 함수는 사용할 수 없다.

날짜 접근은 전용 함수를 등록해 확장할 예정이다. `dayjs` 객체와 메서드는 표현식에 노출하지 않는다.

## 개발 명령

Node.js 24 이상과 npm이 필요하다. `npm ci`로 의존성을 설치한다.

| 명령                   | 동작                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------- |
| `npm run build`        | TypeScript 소스를 Vite로 빌드해 ESM 및 CommonJS 파일과 타입 선언을 `dist/`에 생성한다. |
| `npm run typecheck`    | 소스와 테스트의 TypeScript 타입을 검사한다.                                            |
| `npm test`             | Vitest를 한 번 실행한다.                                                               |
| `npm run test:watch`   | 파일 변경을 감시하고 Vitest를 실행한다.                                                |
| `npm run lint`         | Biome으로 린트 규칙을 검사한다.                                                        |
| `npm run format`       | Biome으로 포맷을 적용한다.                                                             |
| `npm run format:check` | 파일을 수정하지 않고 포맷을 검사한다.                                                  |
