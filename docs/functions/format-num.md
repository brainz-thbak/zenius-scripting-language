# FORMAT_NUM

숫자를 지정한 서식의 문자열로 표시한다.

## 호출 형식

```text
FORMAT_NUM(number, pattern)
```

| 인자      | 평가 값                        |
| --------- | ------------------------------ |
| `number`  | 유한한 `number` 또는 `bigint`. |
| `pattern` | 숫자 서식을 담은 문자열.       |

인자는 정확히 두 개다. 각 인자에는 `GET` 호출을 포함한 표현식을 쓸 수 있다. 평가기가 두 번째 인자의 문자열 값을 읽어 서식을 해석한다.

## 서식

| 서식          | 예               | 동작                                                                         |
| ------------- | ---------------- | ---------------------------------------------------------------------------- |
| 일반          | `General`        | 숫자 크기와 자릿수에 맞춰 표시한다.                                          |
| 자릿수와 공백 | `#,##0.0?`       | `0`은 필수 자리, `#`은 선택 자리, `?`는 여분의 공백을 표시할 수 있는 자리다. |
| 천 단위 축소  | `0.0,,`          | 자리표시자 뒤의 쉼표마다 값을 1,000으로 나눈다.                              |
| 백분율        | `0.00%`          | 서식 끝의 `%`는 값을 백분율로 표시한다.                                      |
| 과학적 표기   | `0.00E+00`       | 가수와 지수를 표시한다.                                                      |
| 분수          | `# ?/?`, `# ?/2` | 소수 값을 분수로 표시한다. 분모를 고정할 수 있다.                            |

숫자는 `0`부터 `9`까지의 문자로 출력한다. 소수점은 `.`, 천 단위 구분자는 `,`를 사용한다. 대분수 서식은 정수부와 분자 사이에 공백 한 칸을 쓴다. [허용 서식](../adr/0012-format-num-scope.md#허용-서식)

`number`의 10진 문자열을 기준으로 반올림한다. 정확히 중간이면 절댓값이 커지는 쪽으로 반올림한다. `bigint`는 정수 자릿수를 보존한 채 서식이 지정한 변환을 적용한다. 반올림한 결과가 0이면 자동 음수 부호를 생략한다. [숫자 정밀도](../adr/0009-numeric-precision.md) · [Excel 서식 호환성](../adr/0011-excel-format-compatibility.md)

서식 길이의 상한은 UTF-16 코드 단위 255개다. `number`에서 만든 결과에도 같은 상한을 적용한다. 최종 템플릿은 `maxOutputLength`의 적용을 받는다. [출력 길이 설정](../api-reference/zsl-options.md)

허용 범위를 벗어난 서식은 `INVALID_NUMBER_FORMAT`으로 거부한다. `MM/DD/YY`, `[h]:mm`, `$#,##0`, `[$-412]0`, `0;[Red](0)`, `0"건"`이 이에 해당한다.

## 오류

| 오류 코드                | 발생 조건과 범위                                                            |
| ------------------------ | --------------------------------------------------------------------------- |
| `INVALID_ARGUMENT_COUNT` | 컴파일할 때 인자가 두 개가 아니면 호출 전체를 가리킨다.                     |
| `INVALID_ARGUMENT_TYPE`  | 평가한 값의 타입이 인자의 요구 조건을 충족하지 않으면 해당 인자를 가리킨다. |
| `INVALID_NUMBER_FORMAT`  | 서식 문법이 잘못됐거나 지원 범위를 벗어나면 두 번째 인자를 가리킨다.        |
| `UNFORMATTABLE_NUMBER`   | 유효한 서식으로 숫자를 표시할 수 없으면 첫 번째 인자를 가리킨다.            |

[오류 클래스와 코드](../api-reference/error-codes.md)

## 예제

```js
import { ZSL } from '@zenius/zsl'

const zsl = new ZSL()
const message = zsl.compile(
  "탐지 건수 ${FORMAT_NUM(GET('alert', 'count') ?? 0, '#,##0')}건",
)

message.evaluate({ alert: { count: 12345 } }) // '탐지 건수 12,345건'
message.evaluate() // '탐지 건수 0건'

const risk = zsl.compile("위험 점수 ${FORMAT_NUM(12.5, '0.00')}")
risk.evaluate() // '위험 점수 12.50'
```
