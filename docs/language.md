# 언어 명세

ZSL 템플릿은 일반 텍스트와 `${...}` 표현식 구간으로 구성된다. 표현식 구간 하나에는 표현식 하나가 들어간다. 템플릿은 텍스트를 보존하고 표현식 결과를 제자리에 삽입해 문자열을 반환한다. `${4 + 6}`만 있는 템플릿의 결과는 문자열 `'10'`이다.

## 표현식

### 리터럴

표현식 입력은 리터럴 하나와 그 앞뒤 공백으로 구성된다. 공백은 생략할 수 있고, 스페이스, 탭, LF, CR을 사용할 수 있다. 뒤쪽 공백을 읽으면 입력이 끝나야 한다. [EBNF](../spec/zsl.ebnf)

- 숫자는 부호 없는 10진 정수 또는 소수다. 소수점 양쪽에는 숫자가 한 자리 이상 있어야 한다. 선행 0을 허용한다. 숫자 값은 유한한 JavaScript `number`로 변환한다. 지수 표기와 10진수 이외의 진법은 허용하지 않는다.
- 문자열은 작은따옴표 또는 큰따옴표로 묶는다. 여는 따옴표와 닫는 따옴표는 같은 종류를 사용한다. `\\`, `\'`, `\"`, `\n`, `\r`, `\t`는 각각 역슬래시, 작은따옴표, 큰따옴표, LF, CR, 탭으로 읽는다. U+0000부터 U+001F까지의 문자를 문자열에 직접 쓸 수 없다.
- `true`, `false`, `null`은 소문자로 쓴다.

소스 범위는 원문의 0부터 시작하는 UTF-16 코드 단위 오프셋이다. 시작 위치를 포함하고 끝 위치를 제외한다. 리터럴의 범위는 앞뒤 공백을 제외한다. 문자열의 범위에는 양쪽 따옴표와 이스케이프 표기가 포함된다. 예를 들어 `'event'` 앞뒤에 스페이스가 한 개씩 있으면 범위는 `[1, 8)`이다. 닫히지 않은 문자열 오류의 범위는 여는 따옴표부터 입력 끝까지다.

### 연산자와 함수 호출

- 중첩 괄호와 사칙연산 `+`, `-`, `*`, `/`
- 삼항 연산 `조건 ? 참일 때의 값 : 거짓일 때의 값`
- 논리 연산 `&&`, `||`와 널 병합 연산 `??`
- 등록된 전용 함수 호출

연산자와 함수 호출의 단계별 범위는 [로드맵](roadmap/)에 있다. 허용 범위와 기대 결과는 [표현식 사례](../tests/zsl.cases.ts)에서 확인할 수 있다.

## 데이터 접근

`GET('event', 'severity')`에서 첫 인자 `'event'`는 호출자가 전달한 컨텍스트의 키다. 나머지 인자는 해당 객체 안에서 읽을 속성 경로다. 컨텍스트가 `{ event: { severity: 6 } }`이면 조회 결과는 `6`이다. 경로가 없을 때의 반환 규칙은 미정이다. [공개 API](api.md)

## 허용 범위

변수 선언, 할당, 함수 선언, 제어문, 점 표기와 대괄호 표기를 통한 직접 속성 접근을 문법에서 제외한다. 검사기는 호출 구문에 있는 함수 이름이 등록돼 있는지 확인한다. ZSL의 표현식에는 전역 변수, 미등록 함수, 라이브러리 객체와 메서드를 노출하지 않는다. 날짜 접근을 지원할 때는 등록 목록에 전용 함수를 추가한다.
