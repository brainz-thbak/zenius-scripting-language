# 템플릿 내장 함수

ZSL 템플릿의 `${...}` 안에서 호출할 수 있는 함수다. 함수 이름은 대소문자를 구분한다.

| 함수                                    | 동작                                           |
| --------------------------------------- | ---------------------------------------------- |
| [`EXIST`](functions/exist.md)           | 컨텍스트 경로에 값이 저장되어 있는지 확인한다. |
| [`GET`](functions/get.md)               | 컨텍스트 경로에서 값을 읽는다.                 |
| [`FORMAT_NUM`](functions/format-num.md) | 숫자를 지정한 숫자 서식의 문자열로 표시한다.   |

파서는 등록된 내장 함수 이름을 호출 구문에서 허용한다. 파싱을 마치면 함수별 인자 수를 검사한다. 인자의 평가 값과 반환 규칙은 각 함수 문서에서 확인할 수 있다. [함수 호출 문법](language.md#함수-호출)
