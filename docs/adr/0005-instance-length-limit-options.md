# 0005 ZSL 인스턴스별 입출력 길이 제한 설정

## 배경

같은 애플리케이션에서 여러 용도의 템플릿을 처리할 수 있다. 용도마다 허용할 원문과 평가 결과의 길이가 다를 수 있다.

## 결정

- `new ZSL(options?)`의 선택 옵션으로 입력과 출력의 길이 제한을 각각 전달한다. 각 인스턴스의 한도는 생성 시 정해진다.
- `compile()`은 해당 인스턴스의 입력 한도를 사용한다. 컴파일된 `Expression`은 해당 인스턴스의 출력 한도로 평가한다.
- 운영 환경에 따라 한도를 바꾸는 소비처는 환경변수나 설정 파일을 읽어 생성자 옵션으로 전달할 수 있다.

## 검토한 방식

| 설정 방식                            | 적용 범위와 사용 조건                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 생성자 옵션                          | 용도별 인스턴스에 정책을 둔다. 같은 프로세스에서 서로 다른 한도를 함께 쓸 수 있다.             |
| 라이브러리에서 환경변수 읽기         | 프로세스 단위의 운영 설정에 적합하다. 여러 용도의 한도를 표현하려면 추가 규약이 필요하다.      |
| `ZSL.config` 전역 설정               | 여러 호출부가 설정 상태를 공유한다. 정책 변경 시점과 테스트 간 상태 관리가 필요하다.           |
| `compile()`·`evaluate()` 호출별 옵션 | 요청마다 한도가 달라질 때 적합하다. 같은 정책을 쓰는 호출에서도 한도를 반복해서 전달해야 한다. |
