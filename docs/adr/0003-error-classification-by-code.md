# 0003 `code`로 오류 원인 판별

## 배경

ZSL 패키지는 ESM과 CommonJS 진입점을 제공한다. 한 프로세스에서 두 진입점을 함께 사용하면 각 진입점은 별도의 오류 클래스 생성자를 갖는다. 한 진입점이 던진 오류를 다른 진입점의 클래스로 `instanceof` 검사하면 같은 원인의 오류여도 `false`가 나온다. [패키지 진입점](../../package.json)

## 결정

- 호출부는 ZSL 오류의 `code`로 원인을 판별한다. 예를 들어 0으로 나누면 두 진입점 모두 `DIVISION_BY_ZERO`를 제공한다. `code` 값은 호출부가 의존하는 공개 계약이다. [공개 오류 API](../api.md#오류와-진단)
- `instanceof`는 오류를 던지는 쪽과 검사하는 쪽이 같은 클래스 생성자를 공유할 때 상속 관계를 확인하는 데 사용한다.
