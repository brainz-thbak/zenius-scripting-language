# 0008 오류 진단의 복사 범위

## 배경

같은 표현식을 여러 번 평가할 때 각 오류의 소스 범위는 평가에 사용하는 AST와 분리되어야 한다. 공개 클래스 `ZslError<Issue>`는 호출자가 추가 속성과 메서드를 가진 진단 타입을 전달하는 데도 사용된다. [alpha.12 로드맵](../roadmap/alpha.12.md) · [공개 오류 API](../api.md#오류와-진단)

## 결정

- 오류마다 진단 배열을 복사한다. 프로토타입이 `Object.prototype`인 진단은 얕게 복사하고, 그 진단의 `span`도 프로토타입이 `Object.prototype`이면 얕게 복사한다. [공통 오류 생성자](../../src/exception/zsl-error.ts)
- 일반 객체의 사본은 진단의 `kind`, `message`, `span`과 범위의 `start`, `end`를 보존한다. 그 밖의 속성은 자체 열거 속성만 사본에 담는다. 원본 참조를 키로 사용하는 `WeakMap`의 상태는 원본에 연결된 채 남는다.
- 사용자 정의 클래스의 진단 인스턴스는 전달받은 객체를 그대로 사용한다. 객체 참조를 유지해야 하는 확장 동작은 클래스 인스턴스에 둘 수 있다.

이 범위는 엔진이 내보내는 소스 범위를 AST에서 분리하면서 클래스 기반 확장의 동작을 보존한다. 일반 진단 객체는 자체 열거 속성으로 확장 데이터를 전달한다.
