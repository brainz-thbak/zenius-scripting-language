# 0004 `GET`의 최종 반환값

## 배경

`GET`은 컨텍스트의 객체와 배열을 경로 중간에서 조회한다. 경로 끝에서 반환하는 값의 범위는 ZSL 리터럴의 값 범위와 같다. [언어 명세](../language.md#데이터-접근)

## 결정

- `GET`의 최종 반환값은 문자열, 불리언, 유한한 숫자, `null`로 확정한다. 조회할 수 없는 경로와 `undefined`는 `null`로 처리한다.
- 최종값이 객체, 배열, `Date`, 함수, `bigint`, `symbol`, `NaN` 또는 무한대이면 전체 호출 범위에 `INVALID_FUNCTION_RESULT` 오류를 보고한다. [평가기 테스트](../../tests/zsl.evaluator.test.ts)
- 날짜를 전달할 때는 호출부에서 문자열이나 유한한 숫자 타임스탬프로 변환한다.
