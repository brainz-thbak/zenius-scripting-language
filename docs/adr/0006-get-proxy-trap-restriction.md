# 0006 `GET`의 `Proxy` 트랩 호출 제한

## 배경

`GET`은 컨텍스트와 중첩 객체에서 자체 데이터 속성을 읽는다. 조회 대상이 `Proxy`이면 속성을 확인하는 과정에서 트랩이 실행될 수 있다. 컨텍스트를 데이터로 다루기 위해 조회 중 트랩 호출을 막는다. [데이터 접근 명세](../language.md#데이터-접근)

## 결정

- 루트 컨텍스트와 중첩 경로에서 속성을 읽기 전에 조회 대상을 검사한다. 조회 대상이 `Proxy`이면 트랩을 호출하지 않고 조회할 수 없는 경로로 처리해 `null`을 반환한다. [`GET` 반환값 ADR](0004-get-result-values.md)
- 구현과 검증은 `0.1.0-alpha.10` 범위에 둔다. 루트 컨텍스트와 중첩 객체에서 각각 `null` 반환과 트랩 호출 횟수 `0`을 확인한다. [alpha.10 로드맵](../roadmap/alpha.10.md) · [평가기 테스트](../../tests/zsl.evaluator.test.ts)
