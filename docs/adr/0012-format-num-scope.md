# 0012 FORMAT_NUM의 숫자 서식 범위

이 ADR은 [ADR 0011](0011-excel-format-compatibility.md)의 `FORMAT_NUM` 서식 범위를 대체한다. [alpha.17 로드맵](../roadmap/alpha.17.md)의 `FORMAT_NUM`에 적용한다.

## 배경

SIEM 템플릿은 탐지 건수와 위험 점수 같은 수치를 표시한다. Excel은 같은 숫자를 서식에 따라 수치, 날짜, 경과 시간 또는 통화로 표시한다. `FORMAT_NUM`의 서식은 SIEM에서 수치를 표시하는 데 필요한 범위로 한정한다.

## 결정

- `FORMAT_NUM(number, pattern)`의 첫 번째 인자는 유한한 `number` 또는 `bigint`다. 날짜·시각 문자열을 포함한 다른 타입은 첫 번째 인자에서 `INVALID_ARGUMENT_TYPE`으로 거부한다.
- `FORMAT_NUM`의 두 번째 인자에는 숫자 서식을 쓴다. 달력 날짜, 시각, `[h]:mm`과 같은 경과 시간 서식은 두 번째 인자에서 `INVALID_NUMBER_FORMAT`으로 거부한다.
- `FORMAT_NUM`은 숫자 `0`부터 `9`, 소수점 `.`, 천 단위 구분자 `,`를 고정해 사용한다. 평가 옵션의 로캘 설정과 로캘별 서식 문법은 지원 범위에서 제외한다. `[$-ko-KR]`, `[$-412]`, `[DBNum1]` 같은 Excel 로캘·숫자 체계 지시자는 두 번째 인자에서 `INVALID_NUMBER_FORMAT`으로 거부한다.
- `FORMAT_NUM`은 `$`, `₩`, `€` 같은 통화 기호와 `[$£-809]`, `[$-x-euro1]` 같은 통화 지시자를 두 번째 인자에서 `INVALID_NUMBER_FORMAT`으로 거부한다.

## 허용 서식

아래 구성과 규칙에 맞는 조합을 허용한다. 정의되지 않은 토큰이나 조합은 두 번째 인자에서 `INVALID_NUMBER_FORMAT`으로 거부한다.

| 구성             | 허용 규칙                                                                                                                         | 서식 예시                 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| 일반             | `General`로 숫자를 표시한다.                                                                                                      | `General`                 |
| 자릿수           | `0`은 필수 자리, `#`은 선택 자리, `?`는 비어 있을 때 공백을 넣는 자리다.                                                          | `0000`, `0.0#?`           |
| 소수점과 천 단위 | `.`은 소수점이다. 자리표시자 사이의 `,`는 천 단위로 묶고, 마지막 자리표시자 뒤의 `,`는 개수마다 값을 1,000으로 나눈다.            | `#,##0.00`, `#,`, `0.0,,` |
| 백분율           | `%`는 값을 100배 하고 `%`를 표시한다.                                                                                             | `0.00%`                   |
| 과학적 표기      | `E+` 또는 `E-` 뒤에 지수 자리표시자를 쓴다.                                                                                       | `0.00E+00`, `0.0E-0`      |
| 분수             | `/` 앞에 분자 자리표시자를 쓰고, 뒤에 분모 자리표시자 또는 양의 정수 분모를 쓴다. 정수부를 둘 때에는 분자 앞에 공백 한 칸을 쓴다. | `# ?/?`, `# ?/2`          |

구역 구분자 `;`, 텍스트 자리표시자 `@`, 조건과 색상 지시자, 리터럴, 공백과 채움 지시자 `_`와 `*`는 거부한다.

## 확인 사례

| 표현식                                    | 기대 결과                              |
| ----------------------------------------- | -------------------------------------- |
| `FORMAT_NUM(1234.5, '#,##0.00')`          | 문자열 `1,234.50`                      |
| `FORMAT_NUM('2026-11-27T05:30:00Z', '0')` | 첫 번째 인자의 `INVALID_ARGUMENT_TYPE` |
| `FORMAT_NUM(42670, 'MM/DD/YY')`           | 두 번째 인자의 `INVALID_NUMBER_FORMAT` |
| `FORMAT_NUM(0.5, '[h]:mm')`               | 두 번째 인자의 `INVALID_NUMBER_FORMAT` |
| `FORMAT_NUM(1234.5, '$#,##0.00')`         | 두 번째 인자의 `INVALID_NUMBER_FORMAT` |
| `FORMAT_NUM(1234.5, '[$-412]#,##0.00')`   | 두 번째 인자의 `INVALID_NUMBER_FORMAT` |
