# 0007 `GET` 컨텍스트의 소비처 책임

이 ADR은 [ADR 0006](0006-get-proxy-trap-restriction.md)과 [alpha.10 로드맵](../roadmap/alpha.10.md)에 명시된 ZSL의 `Proxy` 트랩 차단 요구를 대체한다.

## 배경

`GET`은 컨텍스트와 중첩 객체에서 자체 데이터 속성을 읽는다. 조회 대상이 `Proxy`이면 속성 디스크립터를 확인할 때 트랩이 실행될 수 있다. 웹 브라우저에는 임의의 객체를 트랩 호출 없이 `Proxy`로 판별하는 표준 API가 없다. [데이터 접근 명세](../language.md#데이터-접근)

## 결정

- 소비처가 루트 컨텍스트와 `GET`이 탐색할 중첩 경로를 일반 객체나 배열로 구성해 `evaluate(context)`에 전달한다. 트랩 호출을 피해야 하는 경우 `Proxy`로 감싸기 전의 원본 데이터나 이미 확보한 값을 사용한다. [공개 API](../api.md#평가)
- ZSL은 웹 브라우저와 Node.js에서 같은 자체 데이터 속성 조회 규칙을 적용한다. `Proxy`가 조회 경로에 들어오면 트랩이 실행될 수 있으며, 트랩 호출 0회는 ZSL의 보장 범위 밖이다. [`GET` 반환값 ADR](0004-get-result-values.md)
