# 0013 FORMAT_NUM의 배율, 분수와 길이 제한

이 ADR은 [alpha.17 로드맵](../roadmap/alpha.17.md)의 `0%` 거부 기준을 대체한다. [ADR 0012](0012-format-num-scope.md)가 정한 허용 서식에 배율, 분수 변환, 길이와 오류 규칙을 적용한다.

## 배율과 표기

- 백분율 지시자 `%`는 서식 끝에 둔다. `%` 하나마다 값을 100배 하고 같은 개수의 `%`를 출력한다.
- 자리표시자 사이의 `,`는 자릿수를 세 자리씩 묶는다. 정수부나 소수부 끝의 `,`는 하나마다 값을 1,000으로 나눈다. 대분수의 정수부 끝에 붙은 `,`도 전체 값에 같은 배율을 적용한다. 숫자를 반올림하거나 분수로 나누기 전에 배율을 적용한다.
- 고정 소수점 서식은 정수부 또는 소수부의 자리표시자를 생략할 수 있다. `.00`은 입력의 정수부와 소수 두 자리를 표시하고, `0.`은 정수로 반올림한 값 뒤에 소수점을 출력한다.
- `General`은 `number`의 크기에 따라 지수 표기를 쓸 수 있다. `bigint`는 10진 정수 자릿수를 모두 표시한다.

## 분수 변환

`number`의 10진 문자열과 `bigint`의 정수 자릿수를 기준으로 분자를 계산한다. 고정 분모에서는 배율을 적용한 값의 분수부에 분모를 곱해 분자를 반올림한다. 정수부가 없는 서식은 배율을 적용한 전체 값에 분모를 곱한다.

분모에 자리표시자가 `n`개 있으면 분모는 `10ⁿ − 1` 이하다. 값과의 차이가 가장 작은 분수를 선택한다. 거리가 같으면 절댓값이 큰 쪽을 택한다. 정수부가 0인 대분수에서는 분모 한도 안에 비정수 연분수 수렴분수가 없을 때 정수로 반올림한다. 대분수의 분자가 0이고 분자에 필수 자리 `0`이 없으면 분수부를 생략하고 `?`에 따른 공백을 표시한다.

## 길이와 오류

서식 문자열이 UTF-16 코드 단위 255개를 넘으면 두 번째 인자를 `INVALID_NUMBER_FORMAT`으로 거부한다. `number`의 출력이 255개를 넘으면 첫 번째 인자에 `UNFORMATTABLE_NUMBER`를 보고한다. `bigint`는 이 출력 제한 없이 자릿수를 보존한다. 전체 템플릿 결과에는 `maxOutputLength`가 적용된다. [오류 클래스와 코드](../api-reference/error-codes.md) · [출력 길이 설정](../api-reference/zsl-options.md)

## 확인 사례

| 표현식 또는 동작                                             | 기대 결과                              |
| ------------------------------------------------------------ | -------------------------------------- |
| `FORMAT_NUM(1234, '0%')`                                     | `123400%`                              |
| `FORMAT_NUM(0.0123, '0.0%%')`                                | `123.0%%`                              |
| `FORMAT_NUM(12200000, '#,###.0,')`                           | `12,200.0`                             |
| `FORMAT_NUM(12, '.00')`, `FORMAT_NUM(12, '0.')`              | 각각 `12.00`, `12.`                    |
| `FORMAT_NUM(100000000000, 'General')`                        | `1E+11`                                |
| `FORMAT_NUM(0.6125, '?/?')`, `FORMAT_NUM(0 - 0.6125, '?/?')` | 각각 `5/8`, `-5/8`                     |
| `FORMAT_NUM(0.99999999, '#/#########')`                      | `99999999/100000000`                   |
| `FORMAT_NUM(2147483648, '?/?')`                              | `2147483648/1`                         |
| `FORMAT_NUM(0.08, '# ?/?')`                                  | `0` 뒤에 공백 네 칸                    |
| `FORMAT_NUM(1080, '#, ?/?')`                                 | `1 1/9`                                |
| `0`이 256개인 서식 적용                                      | 두 번째 인자의 `INVALID_NUMBER_FORMAT` |
| 256자리 `bigint`에 `0` 서식 적용                             | 정수 256자리를 모두 출력               |
| `GET`으로 받은 `1e300`에 `0` 서식 적용                       | 첫 번째 인자의 `UNFORMATTABLE_NUMBER`  |
