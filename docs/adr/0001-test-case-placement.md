# 0001 테스트 사례의 배치

## 기존 구조

`zsl.cases.ts`에 리터럴, 연산 결과, 문법·함수 검사 실패 사례를 모아 두었다. 각 테스트 파일은 필요한 사례를 가져와 직접 등록했다. `zsl.suite.ts`의 공통 등록 함수는 미사용 상태였다.

## 결정

- 각 단계에서만 쓰는 사례는 해당 `.test.ts`에 두고 검증 코드 옆의 `it.each()`로 등록한다. 공통 등록 함수는 제거한다.
- 파서와 평가기가 함께 쓰는 리터럴 사례는 공통 파일에 둔다. [공통 리터럴 사례](../../tests/zsl.literal-cases.ts)
