# 0.1.0-alpha.5 템플릿 처리

템플릿의 일반 텍스트를 보존하고, `${...}` 표현식의 평가 값을 제자리에 삽입해 문자열을 만든다.

| 구성        | 문법                    | 적용 규칙                                                                  |
| ----------- | ----------------------- | -------------------------------------------------------------------------- |
| 일반 텍스트 | `4 + 6`, `{event.name}` | 표현식 구간 바깥의 문자와 공백을 그대로 보존한다.                          |
| 표현식 삽입 | `${4 + 6}`              | 구간 안의 표현식 하나를 파싱하고 검사한 뒤, 평가 결과를 문자열로 삽입한다. |
| 혼합 템플릿 | `결과: ${4 + 6}`        | 텍스트와 표현식의 순서를 유지한다.                                         |

템플릿의 평가 결과는 표현식 구간 하나로만 구성된 경우에도 문자열이다. [언어 명세](../language.md) · [공개 API](../api.md#평가)

## 구현 범위

- EBNF에 일반 텍스트와 `${...}` 구간으로 구성된 템플릿 문법을 정의한다. [EBNF](../../spec/zsl.ebnf)
- 템플릿 컴파일러는 텍스트를 `text` 구간으로 저장한다. 표현식 구간은 기존 렉서, 파서와 검사기에 넘기고, 검사된 AST를 `expression` 구간으로 저장한다. 구간을 원문 순서대로 `TemplatePart[]`에 담는다.
- 닫히지 않은 표현식 구간이나 그 안의 문법 및 검사 오류는 템플릿 원문 기준 소스 범위와 함께 보고한다.
- `evaluate(context?)`는 텍스트를 유지하고, AST를 컨텍스트로 평가한 값을 문자열로 바꿔 순서대로 이어 붙인다. 같은 컴파일 결과를 여러 컨텍스트로 평가할 수 있다. [공개 API](../api.md#평가)

## 확인 기준

객체 조회 사례는 `{ event: { name: '로그인', severity: 6 } }`을 컨텍스트로 사용한다.

| 표현식                                                                  | 기대 결과                                                    |
| ----------------------------------------------------------------------- | ------------------------------------------------------------ |
| `4 + 6`                                                                 | 문자열 `"4 + 6"`                                             |
| `{event.name}`                                                          | 문자열 `"{event.name}"`                                      |
| `${4 + 6}`                                                              | 문자열 `"10"`                                                |
| `4 + 6 = ${4 + 6}`                                                      | 문자열 `"4 + 6 = 10"`                                        |
| `${GET('event', 'name')}의 위험도는 ${GET('event', 'severity')}입니다.` | 문자열 `"로그인의 위험도는 6입니다."`                        |
| `결과: ${4 + 6`                                                         | 닫히지 않은 표현식 구간에 대한 문법 오류와 소스 범위         |
| `${event.name}`                                                         | 직접 속성 접근에 대한 문법 오류와 템플릿 원문 기준 소스 범위 |
