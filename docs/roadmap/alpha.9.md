# 0.1.0-alpha.9 컴파일 입력 검증과 템플릿 길이 제한

컴파일 입력을 런타임에 검증하고 템플릿 원문과 평가 결과의 길이 제한을 정한다.

| 구성           | 호출                | 적용 규칙                                                       |
| -------------- | ------------------- | --------------------------------------------------------------- |
| 입력 타입 검사 | `compile(source)`   | 문자열이 아닌 값은 파싱 전에 `INVALID_SOURCE_TYPE` 오류를 낸다. |
| 입력 길이 제한 | `compile(source)`   | 템플릿 원문의 길이를 검사한다.                                  |
| 출력 길이 제한 | `evaluate(context)` | 일반 텍스트와 표현식 결과를 합친 길이를 검사한다.               |

## 구현 범위

1. `compile()` 진입점에서 입력 타입을 검사한다. 타입 오류에 고정 코드 `INVALID_SOURCE_TYPE`을 제공한다. 문자열의 문법 오류는 문법 오류 코드로 보고한다. [공개 API](../api.md#컴파일)
2. 입력과 출력 한도는 `ZSL` 생성자 옵션으로 받는다. 길이의 측정 단위, 한도 생략 시 동작, 한도 초과 오류와 검사 시점을 정하고 ADR에 기록한다. [길이 제한 설정 ADR](../adr/0005-instance-length-limit-options.md)
3. 확정한 길이 제한을 적용한다. 한도 안의 입력과 출력이 성공하는 사례와 한도를 넘으면 오류가 발생하는 사례를 공개 API 테스트로 검증한다. [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

| 입력 또는 동작                                      | 기대 결과                                             |
| --------------------------------------------------- | ----------------------------------------------------- |
| JavaScript에서 `compile(null)`, `compile(42)` 호출  | `code`가 `INVALID_SOURCE_TYPE`인 ZSL 오류가 발생한다. |
| 닫히지 않은 구간이 있는 문자열을 `compile()`에 전달 | `UNTERMINATED_TEMPLATE_EXPRESSION` 오류가 발생한다.   |
| 입력과 출력이 각각 정해진 한도 이하임               | 컴파일과 평가가 성공하고 평가 결과가 그대로 반환된다. |
| 입력 또는 출력이 정해진 한도를 넘음                 | ADR에 정한 시점에 해당 길이 제한 오류가 발생한다.     |
| 한도가 다른 두 `ZSL` 인스턴스에서 같은 템플릿 처리  | 각 인스턴스의 한도가 독립적으로 적용된다.             |
