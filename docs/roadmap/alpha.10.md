# 0.1.0-alpha.10 `GET` 컨텍스트 조회 제한

`GET`이 루트 컨텍스트와 중첩 경로의 속성을 읽을 때 `Proxy` 트랩 호출을 막는다.

| 조회 대상                               | 적용 규칙                                              |
| --------------------------------------- | ------------------------------------------------------ |
| 일반 객체와 배열                        | 자체 데이터 속성을 읽는다.                             |
| `Proxy`가 감싼 루트 또는 중첩 조회 대상 | 경로를 조회할 수 없는 경우로 처리해 `null`을 반환한다. |

## 구현 범위

- `GET`이 각 경로 구간의 속성을 읽기 전에 조회 대상을 검사한다. 루트와 중첩 객체에 같은 규칙을 적용한다. [등록 함수](../../src/functions/functions.ts)
- 자체 데이터 속성, 접근자, 상속 속성, 인자 타입, 최종 반환값에 관한 기존 규칙을 검증한다. 트랩 호출 횟수와 함께 `null` 반환을 두 회귀 사례에 명시한다. [데이터 접근 명세](../language.md#데이터-접근) · [`GET` 반환값 ADR](../adr/0004-get-result-values.md) · [평가기 테스트](../../tests/zsl.evaluator.test.ts)

## 확인 기준

| 입력 또는 동작                                                   | 기대 결과                                         |
| ---------------------------------------------------------------- | ------------------------------------------------- |
| `Proxy`가 감싼 루트 컨텍스트에서 `GET('event', 'severity')` 평가 | `null`을 반환한다. 트랩 호출 횟수는 모두 `0`이다. |
| `event`가 `Proxy`인 컨텍스트에서 같은 식을 평가                  | `null`을 반환한다. 트랩 호출 횟수는 모두 `0`이다. |
| `{ event: { severity: 6 } }`에서 같은 식을 평가                  | 숫자 `6`을 반환한다.                              |
