# 0.1.0-alpha.14 숫자 정밀도와 평가 결과 재입력

템플릿에서 큰 정수 리터럴의 값을 구별하고, 작은 양의 소수 출력은 숫자 리터럴로 다시 컴파일할 수 있게 한다.

| 구성                | 적용 규칙                                                            |
| ------------------- | -------------------------------------------------------------------- |
| 큰 정수 리터럴      | 서로 다른 두 정수 리터럴은 평가 결과에도 서로 다른 값으로 남는다.    |
| 작은 양의 소수 출력 | 지수 없는 10진 표기로 출력해 현재 숫자 문법으로 다시 입력할 수 있다. |

## 구현 범위

- 숫자 리터럴을 읽을 때 큰 정수의 값을 보존하는 표현을 정한다. 산술, AST 스냅샷과 `GET`이 반환하는 JavaScript `number`에 같은 표현을 적용할지도 결정한다. 값이나 타입 계약이 바뀌면 명세와 테스트에 반영한다. [렉서](../../src/lexer/lexer.ts) · [AST 타입](../../src/ast/types.ts) · [평가기](../../src/evaluator/evaluator.ts)
- 템플릿 평가 결과에 작은 양의 소수를 현재 숫자 문법이 수용하는 표기로 렌더링한다. 렌더링한 결과를 새 표현식으로 컴파일해 값이 보존되는지 확인한다. [언어 명세](../language.md#리터럴) · [EBNF](../../spec/zsl.ebnf) · [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

| 입력 또는 동작                                         | 기대 결과                                  |
| ------------------------------------------------------ | ------------------------------------------ |
| `${9007199254740992},${9007199254740993}` 평가         | 문자열 `9007199254740992,9007199254740993` |
| `${0.0000001}` 평가                                    | 문자열 `0.0000001`                         |
| 위 소수 출력을 새 `${...}` 구간에 넣어 컴파일하고 평가 | 다시 문자열 `0.0000001`을 반환한다.        |
