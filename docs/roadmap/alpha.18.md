# 0.1.0-alpha.18 `FORMAT_DATE` 함수

`FORMAT_DATE`는 시간대가 명시된 ISO 날짜·시간 문자열을 지정한 시간대와 서식의 문자열로 변환한다. 이벤트 발생 시각과 최초·최종 관측 시각을 알림에 표시할 때 사용한다.

| 구성        | 문법                                    | 적용 규칙                                                                                                                                                              |
| ----------- | --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 날짜 변환   | `FORMAT_DATE(value, pattern, timeZone)` | 인자는 정확히 세 개이며 모두 문자열로 평가돼야 한다. 결과는 문자열이다.                                                                                                |
| 입력 시각   | `'2026-11-27T05:30:45.120Z'`            | 날짜는 `YYYY-MM-DD`, 시각은 `HH:mm:ss` 형식이다. 둘 사이에 `T`를 넣고, 끝에는 `Z` 또는 `+09:00` 같은 UTC 오프셋을 쓴다. 초의 소수부는 생략하거나 1~3자리로 쓸 수 있다. |
| 출력 서식   | `'yyyy-MM-dd HH:mm:ss.SSS'`             | `yyyy`, `MM`, `dd`, `HH`, `mm`, `ss`, `SSS`는 각각 연도, 월, 일, 24시간제 시, 분, 초, 밀리초다. 공백, `-`, `/`, `:`, `.`을 구분자로 쓸 수 있다.                        |
| 출력 시간대 | `'UTC'`, `'Asia/Seoul'`                 | UTC 또는 IANA 시간대 이름을 지정한다. 입력 시각이 가리키는 같은 순간을 지정한 시간대의 날짜와 시각으로 표시한다.                                                       |

호출부가 보유한 JavaScript `Date`는 ISO 문자열로 변환해 컨텍스트에 넣는다. 날짜 검증과 시간대 변환은 `FORMAT_DATE`에서 수행하고 평가기에는 문자열을 반환한다. [GET 반환값 ADR](../adr/0004-get-result-values.md)

## 구현 범위

- EBNF와 내장 함수 등록 목록에 `FORMAT_DATE`를 추가한다. 인자 수가 다르면 호출 범위를, 인자 타입이나 날짜·서식·시간대 값이 잘못되면 해당 인자 범위를 오류에 표시한다. [EBNF](../../spec/zsl.ebnf) · [등록 함수](../../src/functions/functions.ts)
- 함수 규격과 JavaScript 템플릿 예제를 추가한다. 검사기와 평가기에서 인자 수, 입력 오프셋, 날짜 경계를 넘는 시간대 변환, 오류 범위를 확인한다. 템플릿에서 컨텍스트의 시각과 시각이 누락됐을 때의 문구를 확인한다. [템플릿 내장 함수](../functions.md) · [검사기 테스트](../../tests/zsl.checker.test.ts) · [평가기 테스트](../../tests/zsl.evaluator.test.ts) · [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

| 표현식 또는 동작                                                                                                                                    | 기대 결과                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `FORMAT_DATE('2026-11-27T05:30:00Z', 'yyyy-MM-dd HH:mm', 'Asia/Seoul')`                                                                             | 문자열 `2026-11-27 14:30`                                |
| `FORMAT_DATE('2026-11-27T23:30:45.12Z', 'yyyy-MM-dd HH:mm:ss.SSS', 'Asia/Seoul')`                                                                   | 문자열 `2026-11-28 08:30:45.120`                         |
| `FORMAT_DATE('2026-11-27T14:30:00+09:00', 'yyyy-MM-dd HH:mm', 'UTC')`                                                                               | 문자열 `2026-11-27 05:30`                                |
| `FORMAT_DATE('2026-11-27T05:30:00Z', 'yyyy-MM-dd')`, `FORMAT_DATE('2026-11-27T05:30:00Z', 'yyyy-MM-dd', 'UTC', 'UTC')`                              | 호출 전체에 인자 수 오류가 발생한다.                     |
| `FORMAT_DATE(0, 'yyyy-MM-dd', 'UTC')`                                                                                                               | 첫 인자 `0`의 범위에 타입 오류가 발생한다.               |
| `FORMAT_DATE('2026-02-29T05:30:00Z', 'yyyy-MM-dd', 'UTC')`                                                                                          | 첫 인자의 범위에 유효하지 않은 날짜 오류가 발생한다.     |
| `FORMAT_DATE('2026-11-27T05:30:00', 'yyyy-MM-dd', 'UTC')`                                                                                           | 첫 인자의 범위에 입력 시간대 누락 오류가 발생한다.       |
| `FORMAT_DATE('2026-11-27T05:30:00Z', 'yyyy-WW', 'UTC')`                                                                                             | `'yyyy-WW'`의 범위에 지원하지 않는 서식 오류가 발생한다. |
| `FORMAT_DATE('2026-11-27T05:30:00Z', 'yyyy-MM-dd', 'Bad/Zone')`                                                                                     | `'Bad/Zone'`의 범위에 시간대 오류가 발생한다.            |
| 컨텍스트의 `event.occurredAt`이 `2026-11-27T05:30:00Z`일 때 `${FORMAT_DATE(GET('event', 'occurredAt'), 'yyyy-MM-dd HH:mm', 'Asia/Seoul')}` 평가     | 문자열 `2026-11-27 14:30`                                |
| 빈 컨텍스트에서 `${GET('event', 'occurredAt') == null ? '미확인' : FORMAT_DATE(GET('event', 'occurredAt'), 'yyyy-MM-dd HH:mm', 'Asia/Seoul')}` 평가 | 문자열 `미확인`                                          |
