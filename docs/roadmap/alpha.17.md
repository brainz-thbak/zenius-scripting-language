# 0.1.0-alpha.17 `FORMAT_NUM` 함수

`FORMAT_NUM`은 숫자를 서식에 맞는 문자열로 변환한다. 탐지 건수에는 천 단위 구분자를 넣고, 위험 점수에는 필요한 소수 자릿수를 표시할 수 있다.

| 구성      | 문법                          | 적용 규칙                                                                                                                      |
| --------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 숫자 변환 | `FORMAT_NUM(number, pattern)` | 인자는 정확히 두 개다. 첫 인자는 유한한 `number` 또는 `bigint`로, 두 번째 인자는 문자열로 평가돼야 한다. 결과는 문자열이다.    |
| 정수부    | `0`, `0000`, `#,##0`          | 연속한 `0`만큼 최소 정수 자릿수를 채운다. `#,##0`은 오른쪽부터 세 자리마다 `,`를 넣는다.                                       |
| 소수부    | `0.00`, `0.##`, `#,##0.0#`    | `.` 뒤의 `0`은 반드시 표시할 자리이고 `#`은 필요한 경우에 표시할 자리다. `0` 다음에 `#`을 둘 수 있다. 소수부는 생략할 수 있다. |

소수부가 지정한 최대 자릿수까지 반올림한다. 소수부를 생략하면 정수로 반올림한다. 정확히 중간이면 절댓값이 커지는 쪽을 택한다. `number`의 10진 문자열 표현을 반올림의 기준으로 삼는다. `bigint`의 정수 자릿수는 그대로 보존한다. 천 단위 구분자는 `,`, 소수점은 `.`으로 고정한다. [숫자 정밀도 ADR](../adr/0009-numeric-precision.md)

`GET`으로 읽는 값에 기본값이 필요하면 템플릿에서 `GET('alert', 'count') ?? 0`처럼 지정한다. [널 병합 연산](../language.md#삼항-연산-논리-연산과-널-병합)

## 구현 범위

- EBNF와 내장 함수 등록 목록에 `FORMAT_NUM`을 추가한다. 인자 수가 다르면 호출 범위를, 인자 타입이나 서식이 잘못되면 해당 인자 범위를 오류에 표시한다. [EBNF](../../spec/zsl.ebnf) · [등록 함수](../../src/functions/functions.ts)
- 함수 규격과 JavaScript 템플릿 예제를 추가한다. 검사기와 평가기에서 인자 수, 서식, 반올림, 큰 정수와 오류 범위를 확인하고 집계 알림 템플릿에서 반환 문자열을 확인한다. [템플릿 내장 함수](../functions.md) · [검사기 테스트](../../tests/zsl.checker.test.ts) · [평가기 테스트](../../tests/zsl.evaluator.test.ts) · [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

| 표현식 또는 동작                                                                                      | 기대 결과                                                    |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `FORMAT_NUM(1234567, '#,##0')`                                                                        | 문자열 `1,234,567`                                           |
| `FORMAT_NUM(1234.5, '#,##0.00')`                                                                      | 문자열 `1,234.50`                                            |
| `FORMAT_NUM(12.5, '0.##')`                                                                            | 문자열 `12.5`                                                |
| `FORMAT_NUM(42, '0000')`                                                                              | 문자열 `0042`                                                |
| `FORMAT_NUM(1.005, '0.00')`, `FORMAT_NUM(0 - 1.005, '0.00')`                                          | 각각 문자열 `1.01`, `-1.01`                                  |
| `FORMAT_NUM(9007199254740993, '#,##0')`                                                               | 문자열 `9,007,199,254,740,993`                               |
| `FORMAT_NUM(1)`, `FORMAT_NUM(1, '0', '0')`                                                            | 호출 전체에 인자 수 오류가 발생한다.                         |
| `FORMAT_NUM(null, '0')`, `FORMAT_NUM(1, 0)`                                                           | 각각 `null`, 두 번째 인자 `0`의 범위에 타입 오류가 발생한다. |
| `FORMAT_NUM(1234, '0%')`                                                                              | `'0%'`의 범위에 지원하지 않는 서식 오류가 발생한다.          |
| `{ alert: { count: 12345 } }`로 `탐지 건수 ${FORMAT_NUM(GET('alert', 'count') ?? 0, '#,##0')}건` 평가 | 문자열 `탐지 건수 12,345건`                                  |
