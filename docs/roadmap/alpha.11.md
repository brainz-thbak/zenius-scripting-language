# 0.1.0-alpha.11 템플릿 여는 구분자 이스케이프

일반 텍스트에서 `\${`를 사용해 표현식 여는 구분자 `${`를 출력한다.

| 템플릿 원문               | 적용 규칙                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------- |
| `\${`                     | 앞의 역슬래시를 소비하고 `${`를 일반 텍스트에 추가한다.                                |
| `\\${`                    | 역슬래시 한 개를 일반 텍스트에 추가하고 `${`로 표현식 구간을 연다.                     |
| `${` 앞에 연속된 역슬래시 | 역슬래시 두 개를 출력 한 개로 처리한다. 마지막에 한 개가 남으면 `${`를 이스케이프한다. |

## 구현 범위

- 템플릿 구간 탐색에서 이스케이프된 여는 구분자와 표현식 구간을 구분한다. `${` 앞의 역슬래시를 처리한 뒤 일반 텍스트와 표현식 구간을 원문 순서대로 저장한다. [템플릿 컴파일러](../../src/template/template.ts)
- 여는 구분자가 아닌 위치의 역슬래시를 보존하고, 표현식 내부의 문자열 이스케이프는 문자열 리터럴 규칙을 따른다. 이후 표현식의 진단 범위는 원문 기준으로 계산한다. [언어 명세](../language.md#템플릿) · [EBNF](../../spec/zsl.ebnf)
- 템플릿 테스트에서 이스케이프 대상과 실제 표현식이 섞인 입력을 검증한다. 역슬래시를 출력한 뒤 바로 표현식을 평가하는 사례에는 역슬래시 두 개를 사용한다. [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

표의 입력은 JavaScript 문자열 리터럴로 감싸기 전의 템플릿 원문이다.

| 템플릿 원문         | 기대 결과                                               |
| ------------------- | ------------------------------------------------------- |
| `예시: \${42}`      | 문자열 `예시: ${42}`                                    |
| `예시: \\${42}`     | 문자열 `예시: \42`                                      |
| `\${42} → ${1 + 2}` | 문자열 `${42} → 3`                                      |
| `\${42`             | 문자열 `${42`                                           |
| `${42`              | `UNTERMINATED_TEMPLATE_EXPRESSION`과 원문 범위 `[0, 4)` |
