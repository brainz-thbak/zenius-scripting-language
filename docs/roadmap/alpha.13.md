# 0.1.0-alpha.13 `GET`의 Unicode 키 조회

`GET`은 정준 동등한 Unicode 표기로 저장된 자체 데이터 속성을 조회한다.

| 조회 단계                        | 적용 규칙                                                                                                  |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 이름이 정확히 일치하는 키가 있음 | 현재 자체 데이터 속성 조회 규칙에 따라 그 키를 처리한다.                                                   |
| 정확히 일치하는 키가 없음        | NFC로 정규화했을 때 일치하는 자체 키가 하나면 그 키를 처리한다. 후보가 없거나 여러 개면 `null`을 반환한다. |

## 구현 범위

- alpha.10의 조회 제한을 전제로 루트 키와 경로의 각 속성 이름에 같은 규칙을 적용한다. 일반 객체와 배열에서 자체 데이터 속성을 읽는다. [alpha.10 조회 제한](alpha.10.md) · [데이터 접근 명세](../language.md#데이터-접근) · [등록 함수](../../src/functions/functions.ts)
- 정확히 일치하는 키의 우선순위와 NFC 후보 충돌을 평가기 테스트에 포함한다. 실제 템플릿에서 정준 동등한 키를 읽는 동작도 검증한다. [평가기 테스트](../../tests/zsl.evaluator.test.ts) · [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

| 입력 또는 동작                                                                                  | 기대 결과                             |
| ----------------------------------------------------------------------------------------------- | ------------------------------------- |
| `event` 객체에 `'가'.normalize('NFD')` 키만 있고 값이 `'완료'`인 경우 `GET('event', '가')` 평가 | 문자열 `'완료'`                       |
| 요청한 키와 정확히 일치하는 키와 정준 동등한 다른 키가 둘 다 있음                               | 정확히 일치하는 자체 데이터 속성의 값 |
| 정확히 일치하는 키가 없고 정준 동등한 자체 키가 여러 개 있음                                    | `null`                                |
