# 0.1.0-alpha.4 객체 속성 조회 함수

`GET`을 등록 함수로 제공해 호출자가 전달한 컨텍스트에서 객체 속성을 읽는다.

| 구성      | 문법                           | 적용 규칙                                                  |
| --------- | ------------------------------ | ---------------------------------------------------------- |
| 객체 선택 | `GET('event', 'severity')`     | 첫 인자 `'event'`는 컨텍스트의 키다.                       |
| 속성 경로 | `GET('event', 'source', 'ip')` | 나머지 인자는 선택한 객체에서 순서대로 읽을 속성 이름이다. |

조회 범위는 컨텍스트에 전달된 데이터다. 객체나 속성이 없을 때의 동작은 미정이다. [언어 명세](../language.md#데이터-접근)

## 구현 범위

- EBNF에 함수 이름, 괄호, 쉼표로 구분된 인자의 문법을 정의한다. 렉서는 호출을 구성하는 토큰을 읽고, 파서는 함수 이름과 인자를 `call` AST 노드로 만든다. [EBNF](../../spec/zsl.ebnf)
- 함수 목록에 `GET`을 등록한다. 검사기는 호출 이름이 등록 목록에 있는지 확인한다.
- 평가기는 같은 함수 목록에서 `GET`을 찾아 컨텍스트와 인자를 전달한다. `GET`은 첫 인자로 객체를 선택하고 나머지 경로를 따라 값을 읽는다.

## 확인 기준

조회 사례는 `{ event: { severity: 6, source: { ip: '192.0.2.1' } } }`을 컨텍스트로 사용한다.

| 표현식                         | 기대 결과                                     |
| ------------------------------ | --------------------------------------------- |
| `GET('event', 'severity')`     | 숫자 `6`                                      |
| `GET('event', 'source', 'ip')` | 문자열 `192.0.2.1`                            |
| `4 + GET('event', 'severity')` | 숫자 `10`                                     |
| `event.severity`               | 직접 속성 접근에 대한 문법 오류와 소스 범위   |
| `unknown()`                    | 미등록 함수 호출에 대한 검사 오류와 소스 범위 |
