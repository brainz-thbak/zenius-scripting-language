# 0.1.0-alpha.3 삼항 연산, 논리 연산과 널 병합

삼항 연산으로 조건에 따라 값을 고르고, 논리 연산과 널 병합으로 표현식을 결합한다.

| 구성      | 문법                                   | 적용 규칙                                                                |
| --------- | -------------------------------------- | ------------------------------------------------------------------------ |
| 삼항 연산 | `조건 ? 참일 때의 값 : 거짓일 때의 값` | 조건에 해당하는 가지의 값을 반환한다.                                    |
| 논리 AND  | `a && b`                               | 두 피연산자가 불리언이면 둘 다 참일 때 참이다.                           |
| 논리 OR   | `a \|\| b`                             | 두 피연산자가 불리언이면 하나 이상이 참일 때 참이다.                     |
| 널 병합   | `a ?? b`                               | 왼쪽 값이 `null`이면 오른쪽 값을 사용한다. 그 외에는 왼쪽 값을 유지한다. |

불리언이 아닌 조건과 논리 피연산자의 처리, 연산을 섞어 쓸 때의 우선순위와 결합 방향은 언어 명세에서 정한다. [언어 명세](../language.md)

## 구현 범위

- EBNF에 삼항 연산, 논리 연산과 널 병합의 문법을 정의한다. [EBNF](../../spec/zsl.ebnf)
- 렉서는 연산 기호를 토큰으로 읽는다. 파서는 삼항 연산을 `conditional` 노드로, 논리 연산과 널 병합을 `binary` 노드로 만든다.
- 평가기는 삼항 연산에서 선택한 값, 불리언 피연산자의 논리 연산 결과, 널 병합의 결과를 반환한다.

## 확인 기준

| 표현식                          | 기대 결과                    |
| ------------------------------- | ---------------------------- |
| `true ? 1 : 2`, `false ? 1 : 2` | 각각 `1`, `2`                |
| `true && false`                 | `false`                      |
| `false \|\| true`               | `true`                       |
| `null ?? 10`                    | `10`                         |
| `0 ?? 10`                       | `0`                          |
| `true ? 1`                      | 소스 범위를 포함한 문법 오류 |

검증 사례의 기준은 [표현식 테스트 데이터](../../tests/zsl.cases.ts)다.
