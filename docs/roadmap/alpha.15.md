# 0.1.0-alpha.15 비교 연산자

두 값이 같은지 또는 어느 숫자가 더 큰지 비교한다. 비교 결과는 삼항 연산의 조건과 논리 연산의 피연산자로 쓸 수 있다.

| 구성      | 문법                                 | 적용 규칙                                                                                              |
| --------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 동등 비교 | `a == b`, `a != b`                   | 두 값이 같은지 또는 다른지 불리언으로 반환한다. 서로 다른 종류의 값은 다르다. `null`은 `null`과 같다.  |
| 크기 비교 | `a < b`, `a <= b`, `a > b`, `a >= b` | 두 숫자의 크기를 비교해 불리언을 반환한다. 숫자가 아닌 값에는 해당 피연산자의 범위에 검사 오류를 낸다. |

`number`와 `bigint`는 모두 숫자로 취급한다. 두 표현이 섞이면 각 값이 나타내는 수를 정밀도 손실 없이 비교한다. [숫자 정밀도 ADR](../adr/0009-numeric-precision.md)

우선순위는 높은 순서대로 산술, 크기 비교, 동등 비교, 논리 AND다. `GET`에서 값이 누락되면 동등 비교로 `null`인지 확인하거나, `(GET('event', 'severity') ?? 0) >= 5`처럼 기본값을 지정할 수 있다. [언어 명세](../language.md)

## 구현 범위

- 비교 연산자의 문법과 우선순위를 정의한다. 렉서는 비교 기호를 토큰으로 읽고, 파서는 기존 `binary` AST 노드에 연산자와 두 피연산자를 담는다. [EBNF](../../spec/zsl.ebnf) · [렉서](../../src/lexer/lexer.ts) · [파서](../../src/parser/parser.ts)
- 평가기는 비교 연산에 불리언을 반환하고, 크기 비교에 숫자가 아닌 값이 들어오면 해당 피연산자의 소스 범위를 보고한다. [평가기](../../src/evaluator/evaluator.ts)
- 언어 명세에 비교 규칙을 추가하고 파서와 평가기 테스트에서 우선순위, 비교 결과, 오류 범위를 확인한다. [언어 명세](../language.md) · [파서 테스트](../../tests/zsl.parser.test.ts) · [평가기 테스트](../../tests/zsl.evaluator.test.ts)

## 확인 기준

| 표현식                                                                                     | 기대 결과                                                      |
| ------------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| `1 + 2 >= 3 == true && true`                                                               | `(((1 + 2) >= 3) == true) && true`로 묶이고 `true`를 반환한다. |
| `'5' == 5`, `'5' != 5`                                                                     | 각각 `false`, `true`                                           |
| `1 < 2`, `2 <= 2`, `3 > 2`, `2 >= 3`                                                       | 각각 `true`, `true`, `true`, `false`                           |
| `9007199254740992 == 9007199254740992.0`                                                   | `true`                                                         |
| `9007199254740993 > 9007199254740992.0`                                                    | `true`                                                         |
| 빈 컨텍스트에서 `GET('event', 'severity') == null`                                         | `true`                                                         |
| 빈 컨텍스트에서 `GET('event', 'severity') >= 5`                                            | `GET('event', 'severity')` 범위에 검사 오류가 발생한다.        |
| `{ event: { severity: 6 } }`으로 `${GET('event', 'severity') >= 5 ? '주의' : '정상'}` 평가 | 문자열 `주의`                                                  |
