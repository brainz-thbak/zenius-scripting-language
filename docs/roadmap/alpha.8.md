# 0.1.0-alpha.8 보안 회귀 테스트 추가

ZSL에 데이터를 전달하고 평가 결과를 사용하는 과정에서 보안상 위험한 사용 방식을 찾아 회귀 테스트로 검증한다. [공개 API](../api.md#평가)

## 구현 범위

- ZSL 공개 API와 제품 호출부에서 컨텍스트 구성, 속성 조회, 평가 결과 사용 방식을 확인한다. 각 사용 방식에서 지켜야 할 보안 조건과 현재 구현이 위반하는 동작을 찾는다.
- 확인한 문제마다 안전한 기대 동작을 단언하는 테스트를 작성한다. 문제가 발생하는 경계를 실제로 호출하고, 무엇이 관찰값에서 달라져야 하는지 명시한다.
- 기존 `Proxy` 테스트를 기준으로 삼는다. 루트 컨텍스트와 중첩 값에서 각각 트랩 호출 횟수가 `0`이어야 한다고 단언한다. [평가기 테스트](../../tests/zsl.evaluator.test.ts)

## 확인 기준

| 확인 항목          | 기준                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| 현재 구현에서 실행 | 대상 동작을 실행하고, 안전한 기대 동작을 검사하는 단언에서 실패한다.    |
| 실패 원인 확인     | 실패 메시지의 기대값과 실제 관찰값으로 보안 조건 위반을 확인할 수 있다. |
| 수정 후 재실행     | 같은 테스트가 통과한다.                                                 |

`npm test -- <테스트 파일> -t '<테스트 이름>'`으로 대상 사례를 실행한다. [검증 가이드](../verification.md#테스트-사례)
