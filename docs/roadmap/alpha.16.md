# 0.1.0-alpha.16 `EXIST` 함수

`EXIST`는 `GET`과 같은 경로를 조회하고 마지막 속성의 존재 여부를 불리언으로 반환한다.

| 구성      | 문법                         | 적용 규칙                                                                                                                              |
| --------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 경로 조회 | `EXIST('event', 'severity')` | 첫 인자는 컨텍스트의 키다. 나머지 인자는 차례로 조회할 속성 이름이다. 인자는 두 개 이상이며 각 인자는 문자열로 평가돼야 한다.          |
| 반환값    | `true`, `false`              | 경로가 `undefined` 이외의 값이 저장된 자체 데이터 속성에 도달하면 `true`다. 경로를 조회할 수 없거나 최종 값이 `undefined`면 `false`다. |

각 경로 단계에 `GET`의 자체 데이터 속성 조회와 Unicode NFC 일치 규칙을 적용한다. 접근자의 getter는 호출하지 않는다. 마지막 속성에 `null`, `false`, `0`, 빈 문자열, 객체 또는 배열이 저장돼 있어도 `true`다. [데이터 접근 명세](../language.md#데이터-접근)

## 구현 범위

- `EXIST`를 최소 인자 수가 2인 함수로 등록하고 `GET`과 경로 조회 로직을 공유한다. 인자 수가 부족하면 호출 범위에, 문자열이 아닌 인자는 해당 인자의 범위에 검사 오류를 낸다. [등록 함수](../../src/functions/functions.ts)
- 언어 명세에 `EXIST`의 반환 규칙을 추가한다. 검사기와 평가기 테스트에서 인자 검증, 경로 조회와 `GET`의 기존 동작을 확인하고 템플릿에서 불리언 결과를 삼항 조건으로 사용한다. [언어 명세](../language.md) · [검사기 테스트](../../tests/zsl.checker.test.ts) · [평가기 테스트](../../tests/zsl.evaluator.test.ts) · [템플릿 테스트](../../tests/zsl.template.test.ts)

## 확인 기준

| 입력 또는 동작                                                                                | 기대 결과                                  |
| --------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `{ event: { severity: 6 } }`에서 `EXIST('event', 'severity')`                                 | `true`                                     |
| `{ event: { severity: null } }`에서 `EXIST('event', 'severity')`                              | `true`                                     |
| `{ event: {} }`에서 `EXIST('event', 'severity')`                                              | `false`                                    |
| `{ event: { source: {} } }`에서 `EXIST('event', 'source')`와 `EXIST('event', 'source', 'ip')` | 각각 `true`, `false`                       |
| `event`에 `'가'.normalize('NFD')` 키만 있고 `EXIST('event', '가')`를 평가함                   | `true`                                     |
| 경로의 마지막 속성이 접근자이거나 값이 `undefined`임                                          | getter를 호출하지 않고 `false`를 반환한다. |
| `EXIST('event')`                                                                              | 호출 범위에 인자 수 오류가 발생한다.       |
| `EXIST('event', 1)`                                                                           | `1`의 범위에 인자 타입 오류가 발생한다.    |
| 빈 컨텍스트에서 `${EXIST('event', 'severity') ? '있음' : '없음'}` 평가                        | 문자열 `없음`                              |
