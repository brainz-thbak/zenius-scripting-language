# API 레퍼런스

패키지 `@zenius/zsl`의 공개 타입, 메서드, 오류를 조회한다. 패키지 로딩과 전체 사용 흐름은 [공개 API 가이드](../api.md)를 참고한다.

## 컴파일과 평가

| 항목                                             | 종류       | 요약                                          |
| ------------------------------------------------ | ---------- | --------------------------------------------- |
| [`ZSL`](zsl.md)                                  | 클래스     | 템플릿을 컴파일하는 인스턴스를 생성한다.      |
| [`ZSL.compile()`](compile.md)                    | 메서드     | 템플릿 원문을 파싱하고 검사한다.              |
| [`Expression`](expression.md)                    | 타입       | 컴파일된 템플릿의 평가와 AST 조회를 제공한다. |
| [`Expression.evaluate()`](evaluate.md)           | 메서드     | 컨텍스트를 사용해 결과 문자열을 생성한다.     |
| [`Expression.getAstSnapshot()`](ast-snapshot.md) | 메서드     | 템플릿 AST의 복사본을 반환한다.               |
| [`ZslOptions`](zsl-options.md)                   | 인터페이스 | 입력 길이와 출력 길이의 한도를 설정한다.      |

## 오류와 진단

| 항목                                 | 종류        | 요약                                          |
| ------------------------------------ | ----------- | --------------------------------------------- |
| [`ZslError`](zsl-error.md)           | 추상 클래스 | ZSL 오류의 공통 코드와 진단 배열을 제공한다.  |
| [`ZslIssue`](zsl-issue.md)           | 인터페이스  | 진단 메시지와 원문 범위를 담는다.             |
| [오류 클래스와 코드](error-codes.md) | 목록        | 공개 오류 클래스의 발생 조건과 코드를 찾는다. |
